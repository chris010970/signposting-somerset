# Analytics: design record and data

Analytics runs as a tab on the tools page (`/tools/#analytics`); its working code is in `build/tools/analytics/`.

- `DESIGN.md`: what was decided and why. Read this first.
- `analytics.webp`: a screenshot.
- `make_analytics_data.py`: rebuilds `docs/assets/analytics-lsoa.geojson`.

The earlier stand-alone version (when Analytics was a tab in the directory) is in the history, at commit `3d48734`.
